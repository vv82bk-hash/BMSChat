1. ОБЩИЕ СВЕДЕНИЯ

BMSChat — мобильное приложение для закрытой команды «Отряд Боба Марли».

1.2. Слоган
«Двигай. Вдохновляй»

1.3. Тип проекта
Приватный мессенджер для страйкбольной команды (до 100 человек).

1.4. Платформы
Платформа	Технология	Статус

Серверная	Node.js 18+	Основная

Обеспечить закрытую, безопасную и удобную коммуникацию между бойцами страйкбольной команды «Отряд Боба Марли», заменив разрозненные мессенджеры (WhatsApp, Telegram) единым инструментом.

Соответствие законам РФ	0 штрафов от Роскомнадзора
